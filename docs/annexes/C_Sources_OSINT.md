# Annexe C — Sources ouvertes (OSINT) consultées ou identifiées

> *Version du plan : 0.5 (octobre 2026) · Dépendance à l'outil Polarion : **faible** (registre de sources ; seul le § 7 concerne l'outil) · Historique : [CHANGELOG](../../CHANGELOG.md) · Carte du dépôt : [guide de lecture](../GUIDE_DE_LECTURE.md).*

> **En bref**
> - **À quoi sert cette annexe.** Elle liste les sources ouvertes (OSINT, *open source intelligence* : sites officiels, communiqués, offres d'emploi, notes de version) sur lesquelles reposent les faits cotés [C] ou [P] dans les documents, pour qu'un relecteur puisse les vérifier.
> - **Qui la lit.** Les animateurs des ateliers de validation (doc. 05), qui reconsultent chaque source avant de figer un fait dans l'outil.
> - **Comment lire.** Classement par thème ; les références **S-n** du § 1 bis sont celles citées par le document 01 ; la mention « (cité : …) » indique où la source est utilisée, « non citée dans le corpus » signale une source identifiée mais non exploitée.

> Campagne de recherche d'octobre 2026. Certaines pages n'ont été consultées qu'à travers les extraits d'un moteur de recherche, l'accès direct étant impossible depuis l'environnement de recherche. Les URL sont fournies pour vérification et doivent être reconsultées lors des ateliers (document 05). Classement par thème.
